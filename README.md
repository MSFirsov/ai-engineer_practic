# RAG с нуля

Система вопросов и ответов по документу, написанная без фреймворков: только `openai` и `numpy`. Цель — разобраться, как устроен RAG (Retrieval-Augmented Generation) изнутри, и улучшать его шаг за шагом.

В качестве документа используется `handbook.txt` — справочник сотрудника вымышленной компании «Тундра Лабс».

## Как это работает

```
ИНДЕКСАЦИЯ (при запуске)                    ЗАПРОС

handbook.txt                                 вопрос
    │ нарезка по абзацам                       │ эмбеддинг
    ▼                                          ▼
 куски с заголовком раздела                 вектор вопроса
    │ эмбеддинги                               │ косинусная близость
    ▼                                          ▼
 матрица векторов  ─────────────────────▶  top-k кусков
                                               │ промпт: «отвечай только по контексту»
                                               ▼
                                            LLM → ответ
```

1. Документ режется на абзацы. К каждому абзацу приписывается заголовок его раздела, чтобы кусок был понятен без соседей.
2. Каждый кусок превращается в вектор моделью эмбеддингов.
3. Вопрос тоже превращается в вектор, и по косинусной близости находятся самые похожие куски.
4. Найденные куски вставляются в промпт. Модель отвечает только по ним, а если ответа нет, говорит «В документе этого нет».

## Запуск

Нужны [uv](https://docs.astral.sh/uv/) и любой сервер с OpenAI-совместимым API. Я использую [LM Studio](https://lmstudio.ai/) с двумя моделями:

- `google/gemma-4-e4b` — чат-модель;
- `text-embedding-bge-m3` — модель эмбеддингов.

В LM Studio нужно загрузить обе модели и запустить локальный сервер (вкладка Developer → Start Server).

```bash
uv sync
cp .env.example .env
uv run rag.py
```

## Настройки

Задаются в `.env`:

| Переменная | Назначение | По умолчанию в `.env.example` |
|---|---|---|
| `OPENAI_BASE_URL` | адрес API | `http://localhost:1234/v1` (LM Studio) |
| `OPENAI_API_KEY` | ключ API | `lm-studio` (LM Studio его не проверяет) |
| `CHAT_MODEL` | модель для ответов | `google/gemma-4-e4b` |
| `EMBED_MODEL` | модель эмбеддингов | `text-embedding-bge-m3` |

Чтобы подключить облачного провайдера, достаточно поменять эти значения.
